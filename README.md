🏥 Hospital Emergency Room Dashboard

An interactive Hospital Emergency Room Dashboard built in Microsoft Excel using Power Query, Power Pivot, DAX, Pivot Tables, and Pivot Charts. This project transforms raw hospital data into meaningful insights, enabling analysis of patient flow, admissions, wait times, referrals, demographics, and overall emergency room performance through an interactive dashboard.

📌 Project Overview

This dashboard provides a comprehensive overview of Emergency Room (ER) operations by analyzing patient records. The raw CSV dataset was cleaned and transformed using Power Query, a Calendar Table was created for time-based analysis, and DAX measures were used to calculate important KPIs.

The dashboard allows users to filter data by Year and Month, making it easy to analyze trends and monitor hospital performance.
